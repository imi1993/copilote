Installer le copilote dans Chrome

Gratuit, sans compte, sans Chrome Web Store. Environ 2 minutes. Les dessins ci-dessous sont des illustrations : votre écran peut différer légèrement.

1Télécharger
2Extraire le fichier
Ouvrez le dossier Téléchargements. Clic droit sur copilote-extension.zip, puis Extraire tout…, puis Extraire. Un dossier copilote-extension apparaît.
3Ouvrir la page des extensions
Dans Chrome, tapez dans la barre d'adresse : chrome://extensions puis Entrée.
ILLUSTRATION
chrome://extensions
ExtensionsMode développeur
Activez l'interrupteur Mode développeur (en haut à droite).
4Charger le dossier
Cliquez sur Charger l'extension non empaquetée, choisissez le dossier copilote-extension (celui qui contient le fichier manifest.json), puis Sélectionner le dossier.
ILLUSTRATION
Charger l'extension non empaquetéeEmpaqueterMettre à jour
5L'épingler
Cliquez sur l'icône puzzle en haut à droite de Chrome, puis sur l'épingle à côté de Copilote de réunion.
6Pendant une réunion
Ouvrez Meet, Zoom ou Teams dans Chrome (Zoom : « Rejoindre depuis le navigateur »). Un badge OK apparaît sur l'icône. Cliquez sur l'icône, ou tapez Alt + Maj + C. Le panneau s'ouvre à droite. Chrome peut demander une autorisation : c'est normal. Rien ne démarre sans vous.
Test sans réunion : ouvrez une vidéo YouTube en anglais, cliquez sur l'icône. La première fois, le moteur de transcription met environ 1 minute à se préparer (connexion internet nécessaire).

Vie privée : aucun audio enregistré, texte gardé dans votre navigateur. Prévenez les participants. Retour au copilote
